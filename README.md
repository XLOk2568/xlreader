# XLreader

一个面向 Wear OS 的极简 EPUB 阅读器。

打开就是本地文件列表，点开一本书就能直接阅读，没有书城、没有同步、没有联网权限，也没有复杂动画。

初次使用请授权文件管理权：
`adb shell appops set --uid com.dertefter.wearfiles MANAGE_EXTERNAL_STORAGE allow`

除了基本阅读功能外，XLreader 还尝试探索一种更适合手表的交互方式：

**体感手势阅读。**

通过加速度计记录手腕姿态，可以将特定动作映射为翻页、返回、点击等操作。手势支持录制、编辑、重命名、启停、多动作组合等配置，让手表在阅读时不再过度依赖触摸屏。

## 特性

### 为阅读而设计

- 纯黑背景
- 灰阶文字
- 低饱和强调色
- 无缩放、渐变、位移动画
- 长时间阅读更舒适
- 记录上次阅读书籍
- 极简UI，小白也能轻松上手

### 面向手表优化

- Wear OS 3+
- Jetpack Compose for Wear OS
- Release APK 约 2 MB
- Baseline Profile 优化
- 完全离线运行

### 体感手势系统

不同于传统阅读器的点击与滑动操作，XLreader 支持基于手表传感器的体感交互。

用户可以：

- 录制自己的手势
- 自定义角度范围
- 调整识别容差
- 配置检测间隔
- 映射动作行为

支持的动作包括：

- 向上翻页
- 向下翻页
- 返回
- 单击
- 退出

本质上，这是一个轻量化的姿态识别系统，而不仅仅是一个简单的翻页功能。

### 零第三方 EPUB 库

EPUB 解析完全自行实现：

- ZIP 解包
- OPF 解析
- NAV / NCX 目录解析
- XHTML 文本提取
- 图片处理

不依赖 Readium、epublib 等第三方阅读库，以尽可能控制体积与性能。

### 完全离线

- 不联网
- 不上传数据
- 不收集统计信息

### 支持设置导出导入

- 查看/修改app自身data目录
- 便于跨平台与多个设备间记录设置
- 详见设置/数据目录与备份



所有文件、缓存与阅读记录均保存在本地设备中。
